Xuất Keystore đã mã hóa bằng PBKDF2 + AES-GCM hoặc thu hồi bộ khóa hiện tại.

Về Giao Thức Bảo Mật
  • Thuật toán: ElGamal–AES-256-GCM
  • Chữ ký số: ElGamal Signature + SHA-256
  • Quản lý khóa: PBKDF2 (100k) + AES-GCM
  • Tham số nhóm: RFC 3526 MODP 2048-bit
